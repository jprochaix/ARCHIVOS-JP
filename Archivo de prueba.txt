Configuración rápida : si ya has hecho algo así antes.

Crear un nuevo repositorio en la línea de comandos
echo "# ARCHIVOS-JP" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -m main
git remote add origin https://github.com/jprochaix/ARCHIVOS-JP.git
git push -u origin main


O bien, actualiza un repositorio existente desde la línea de comandos.
git remote add origin https://github.com/jprochaix/ARCHIVOS-JP.git
git branch -M main
git push -u origin main
